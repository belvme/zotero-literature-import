# 浏览器与插件补全文

仅在全文依赖浏览器登录、用户明确要求插件，或本机接口不支持所需操作时读取。浏览器检索/下载与 Zotero 入库分开处理。

- 优先使用已有的知网/EBSCO 标签页，核对题名、作者、卷期页码及全文格式。摘要和“链接全文”只是入口，不证明存在 PDF。
- 页内 DOM 通常不包含 Chrome 工具栏。需要点击 Zotero 插件时，读取可用 Computer Use 技能并遵循当前工具支持的入口；不能凭某一个接口的 `apps: []` 认定所有桌面控制不可用。
- 插件保存前核对 Zotero 已运行、保存目标正确，且没有同一文献的既有条目。保存后仍需通过本机接口核对附件，不能只看插件提示。
- 下载定位使用已观察到的完整 `href` 或准确控件名称，避免模糊 `Download` 命中“Download Statistics”。`downloadMedia` 适用于实际文件链接；按钮没有下载 URL 时，使用点击和受支持的下载事件方法。
- 下载监听和点击按当前工具文档执行。不要把耗时点击、等待和全页读取堆进会使运行会话被重置的短超时调用。等待失败后先检查实际文件、子附件、页面状态及下载弹窗，再重试。
- 只有“下载即将完成”提示仍不算落盘成功。使用工具返回的保存路径；必要时查询用户指定目录或系统配置的下载目录。不能只假设 `C:\Users\…\Downloads`。
- 只提供 HTML 时，保留其真实格式。如果另存页面正文，标为“HTML 文字副本”，说明未包含的图表与照片，不冒充数据库原版文件。
- 标签页失效时列出当前标签页并重新绑定；保留登录会话，不反复重启 Chrome。安全检查拒绝浏览器内部地址或停止控制时，不通过其他浏览器表面或底层命令绕过。
- 本地接口不自动继承浏览器学校登录。不要复制 cookies、会话密钥或浏览器凭据来下载。下载完成后返回本机接口附到现有条目；不要为附文件再次新建父条目。
