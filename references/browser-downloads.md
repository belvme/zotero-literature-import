# 浏览器与插件补全文

需要页面检索、机构登录确认或浏览器下载时读取；Connector MCP 另见 [connector-mcp.md](connector-mcp.md)。浏览器检索/下载与 Zotero 文件入库分别核对。

- 用户优先内置浏览器和已有知网/EBSCO 标签页，不把内置浏览器与 Chrome 当成同一会话。首次使用平台前核实学校标识；已有明确确认且会话正常时无需逐篇重问。机构名称可由页面或用户确认，不能从普通个人登录、MCP 在线状态推断。
- 核对题名、作者、卷期页码及全文格式。搜索页找到唯一且身份匹配的题名链接后可直接进入论文，不重复走网站首页。摘要和“链接全文”只是入口，不证明存在 PDF。
- 页内 DOM 不代表扩展工具栏能力。用户要求插件时，优先可用的 Connector MCP；不可用再按当前浏览器工具支持的方式操作，不无依据转到 Chrome 或直接调用 `saveItems` 后声称使用插件。
- 插件保存前核对原条目、当前网页和目标分类；已有条目并不禁止用户授权的重新抓取，但要记录新旧 key 并归并。保存后通过本机接口核对实际附件，不能只看插件提示。
- 下载定位使用已观察到的完整 `href` 或准确控件名称，避免模糊 `Download` 命中“Download Statistics”。`downloadMedia` 适用于实际文件链接；按钮没有下载 URL 时，使用点击和受支持的下载事件方法。
- 下载监听和点击按当前工具文档执行。使用稳定链接/控件，复用同批操作，减少全页读取和截图；需要确认页面身份、登录变化或异常时再取必要状态。不要把耗时点击、等待和全页读取堆进会使运行会话被重置的短超时调用。等待失败后先检查实际文件、子附件、页面状态及下载弹窗，再决定重试。
- 只有“下载即将完成”提示仍不算落盘成功。使用工具返回的保存路径；必要时查询用户指定目录或系统配置的下载目录，不能写死个人路径。
- 只提供 HTML 时，保留其真实格式。如果另存页面正文，标为“HTML 文字副本”，说明未包含的图表与照片，不冒充数据库原版文件。
- 标签页失效时在同一已选浏览器列出当前标签页并重新绑定；保留登录会话，不反复重启浏览器。安全检查拒绝浏览器内部地址或停止控制时，不通过其他浏览器表面或底层命令绕过。验证码交给用户；`USER_CANCELED` 先确认原因，实际用户取消或安全阻断不得换接口绕过，确认并非主动取消且无安全阻断后才检查副作用并选择正常页面下载。
- 页面 DOM 中的验证码文案或单次 `isVisible()` 不能独立证明当前正在验证。若截图与 DOM 矛盾，核对控件实际位置及显示状态；知网页面可能把预载控件放在远离视口的位置。不要为隐藏的预载控件反复要求用户验证，也不要隐藏或绕过真实挑战。
- 本地接口不自动继承浏览器学校登录。不要复制 cookies、会话密钥或浏览器凭据来下载。下载完成后返回本机接口附到现有条目；不要为附文件再次新建父条目。

## EBSCO 快速路径

- 使用用户所在机构提供的 EBSCO 入口。机构校徽结合“机构登出”可核实会话；MyEBSCO 是个人账号，通常无需另登录个人账号。
- 按完整题名或 DOI 搜索；结果即使很多，也可直接进入题名、作者、年份、卷期页码完全匹配的记录。不把原文与 A Comment、重印或 Algebra and Statistics 等同作者其他文章混淆。
- 进入 `/search/details/` 的匹配页后优先 Connector 的 `EBSCO Discovery Layer` 翻译器及 `save_and_check_pdf`。实测能自动保存全文 PDF；先等并查附件，避免同时手动下载造成重复。不根据“保存”按钮文字推断它是 Zotero 按钮。
- “PDF 全文”和页数、嵌入阅读器说明页面有全文；详情页“下载”可能也含引用导出。确实缺 PDF 时进入已观察到的 `/viewer/pdf/` 链接，检查实际阅读器下载控件，不能把阅读器 HTML 链接直接当 PDF 发给下载 API。
- EBSCO 元数据题名常带末尾句点，归并前可规范化句点和空白；结合 DOI、作者、年份核对，保留原笔记和分类，核验附件后才软删除本次重复项。
