# zotero-literature-import · 文献全文获取与 Zotero 导入

用于文献入库和补全文的 AI Agent Skill。围绕指定文献清单，查找可获取的 PDF 或 HTML 全文，保存到 Zotero，并继续核对附件是否实际存在、内容是否对应目标文献。适合新建文献条目、为已有条目补 PDF，以及按目标分类整理资料。

由 **belvme** 维护。技能规则见 [SKILL.md](SKILL.md)，配套参考文件和脚本随仓库提供。

## 主要功能

| 场景 | 处理方式 |
| --- | --- |
| 新文献入库 | 核对题名、作者、年份、DOI 等元数据，查重后保存条目。 |
| 已有条目缺全文 | 将核对后的文件附到已有父条目，避免为补 PDF 再建重复条目。 |
| 只有 HTML 全文 | 保存并标明实际格式，说明与原版 PDF 的差异。 |
| 库中可能存在重复 | 结合 DOI、题名、年份等信息列出候选，确认后按授权范围整理。 |
| 需要核对保存结果 | 检查子附件及实际文件，区分元数据入库、全文取得和附件落盘。 |

可配合知网、EBSCO、出版商及大学仓储等来源使用。优先通过 Zotero 本机接口保存和核对；需要数据库登录或用户明确要求浏览器插件时，再使用相应浏览器操作。机构入口由使用者自行配置，全文获取取决于来源的实际访问权限。

## 输入与交付

- 文献清单：题名必需，DOI、年份、作者和来源链接有助于准确匹配。
- 保存目标：Zotero 文库或分类，以及是否允许整理重复项。
- 已有材料：已下载的全文文件、已有条目信息，或需要补附件的范围。

交付会汇总唯一文献数、PDF 数、HTML 数、重复候选和缺失项，并说明实际使用的保存通道及附件核对情况。

## 安装与调用

将本仓库下载到所用 AI 工具的技能目录，文件夹命名为 `zotero-literature-import`，确保其下直接包含 `SKILL.md`。

任务输入：文献清单、目标分类。

> 使用 zotero-literature-import，为这些文献查找全文并导入指定分类，核对实际附件，报告缺失项和重复候选。

## 运行条件与交付

需要 Zotero 桌面应用和可用的本机 API；浏览器用于需要登录的全文来源，写入按本机接口要求完成授权。

配套只读核查脚本使用 Python 3，仅查询本次清单中的文献并生成报告。可选安装 `pypdf`，进一步检查 PDF 页数和可读性：

```bash
python scripts/audit_zotero.py --manifest papers.json --output audit.json
```

`papers.json` 支持文献数组，或 `{"references":[...]}`；每项需要 `title`，可附带 `doi`、`year` 和 `id`。脚本不执行写入；报告中的相似题名和其他候选需继续核对文献身份。

依照技能说明执行并核对实际输出。需使用本机应用、数据库或浏览器登录时，请在自己的环境中配置路径、来源和权限。

## 文件结构

- `SKILL.md`：触发条件、工作流程及核对要求。
- `agents/openai.yaml`：Agent 显示名称与默认提示。
- `references/`：按任务需要读取的补充说明。
- `scripts/`：配套检查脚本；使用方法见技能说明。
